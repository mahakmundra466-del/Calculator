CALCULATOR:-
A responsive calculator designed to perform basic arithmetic operations through a clean and user-friendly interfance.
I created this project as part of web development learning journey to practice HTML, CSS, and Javascript.

FEATURES:-
1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Clear/reset functionality
6. User-friendly interface
7. Responsive design
   
TECHNOLOGIES USED:-
1. HTML5
2. CSS3
3. Javascript
   
HOW TO USE:-
1. Open the calculator in your web browser.
2. Enter numbers using the calculator buttons.
3. Select the required arithmetic operation.
4. View the result on the display.
